# Yb ファイバーアンプ シミュレータ

ブラウザだけで動く Yb 添加ファイバー増幅器の定常シミュレータです。`index.html` をブラウザで開くと使えます（ビルド不要、外部依存は Google Fonts のみ）。

## できること
- **ファイバー品種の一覧**: コア励起 (4/125, 6/125)、ダブルクラッド (6/125, 10/125, 15/130)、高出力 LMA (20/400, 25/250, 25/400, 30/250, 30/400)、ロッド型 (40/200) の代表値を選ぶと、形状と吸収スペックがまとめて入ります
- ドープ量はスペックシートと同じ形（クラッド吸収 / コア吸収 [dB/m] と基準波長 915・920・940・976 nm）、または Yb 濃度で指定
- **ガラス組成**: アルミノシリケート / ゲルマノシリケート / リン酸シリケートの断面積を内蔵。実測データ（CSV・TXT、2 列または 3 列、単位は自動判定）を貼り付けかファイルで読み込めます
- ファイバー長・コア/クラッド径・NA・寿命・背景損失、励起（クラッド/コア、前方/後方、波長）、信号（波長・入力）を指定
- 出力: パワー分布 (W / dBm)、反転分布と透明点、熱負荷、ASE スペクトル、**利得スペクトル**（ピーク・3 dB 帯域）
- **詳細な出力値**: OSNR (0.1 nm)、飽和パワー（信号・励起）、飽和エネルギー、蓄積エネルギー、取り出し可能エネルギー、Aeff、Leff、SRS / SBS しきい値の目安など
- **パラメータ掃引**: 励起パワー、前方励起の割合、ファイバー長、ドープ量、コア径、信号入力、信号波長、励起波長。3〜201 点。縦軸は 10 種類の指標から選べます
- **2 次元マップ**: 2 つの量を同時に動かして（最大 61×61 点）、指標をカラーマップで表示。現在の条件と最良点を表示
- 掃引・マップは複数の Web Worker で並列計算します。結果は CSV でコピーできます

## モデル
- 2 準位の定常レート方程式 + 伝搬方程式。前方/後方を交互に積分し、端面出力の相対変化が 1e-6 未満になるまで反復（Heun 法・指数積分）
- ASE は波長グリッド上の前方/後方チャネル（自然放出項 2hνΔν·Γσₑ N₂）
- 信号・コア励起のオーバーラップはガウスモード近似（Marcuse）、クラッド励起は面積比
- 吸収スペックから濃度への換算: クラッド吸収は α = 4.34·(a_core/a_clad)²·σa(λ)·N、コア吸収は α = 4.34·Γ(λ)·σa(λ)·N
- 内蔵の断面積は各ガラス組成の代表的なスペクトル形状をガウス関数和で再現した近似で、測定値そのものではありません（0.25 nm 間隔の表 + 線形補間）
- ファイバー品種の値は代表的な目安で、特定の製品のスペックではありません
- SRS / SBS は伝搬を解かず、しきい値の目安（16·Aeff/(gR·Leff)、21·Aeff/(gB·Leff)）のみ
- フォトダークニング、温度依存性、パルス動作、端面反射は考慮していません
