# Yb ファイバーアンプ シミュレータ

ブラウザだけで動く Yb 添加ファイバー増幅器の定常シミュレータです。`index.html` をブラウザで開くと使えます（ビルド不要、外部依存は Google Fonts のみ）。

## できること
- ファイバー長・コア/クラッド径・NA・Yb 濃度・寿命・背景損失、励起（クラッド/コア、前方/後方、波長）、信号（波長・入力）を指定
- 信号・前方/後方励起・前方/後方 ASE のファイバー内分布（W / dBm）
- 反転分布 N₂/N と信号波長の透明点、熱負荷 (W/m)
- 出力端・入力端の ASE スペクトル (dBm/nm)
- 励起パワー・ファイバー長・信号入力・信号波長・励起波長の掃引（スロープ効率、最適長）
- 分布と掃引結果の CSV コピー

## モデル
- 2 準位の定常レート方程式 + 伝搬方程式。前方/後方を交互に積分し、端面出力の相対変化が 1e-6 未満になるまで反復（Heun 法・指数積分）
- ASE は波長グリッド上の前方/後方チャネル（自然放出項 2hνΔν·Γσₑ N₂）
- 信号・コア励起のオーバーラップはガウスモード近似（Marcuse）、クラッド励起は面積比
- 断面積は代表的な Yb:アルミノシリケートの値に合わせたガウス関数和の近似
- 非線形効果、フォトダークニング、温度依存性、パルス動作、端面反射は考慮していません
