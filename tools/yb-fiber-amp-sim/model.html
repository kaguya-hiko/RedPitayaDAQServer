Ybファイバーアンプの計算モデル

シミュレータが実際に計算している式を、コードと同じ順序で書き出しました。後半では、モデルの仮定が実機とずれる箇所を、このモデル自身で計算した感度の例と合わせて整理しています。

1何を解いているか

ファイバー軸方向 \(z\)（\(0 \le z \le L\)）の 1 次元・定常状態のモデルです。Yb³⁺ を 2 準位系（基底 \({}^2F_{7/2}\)、励起 \({}^2F_{5/2}\)）として扱い、各位置の上準位占有率 \(n_2(z)\) と、信号・励起・ASE の各光パワー \(P_k(z)\) を同時に求めます。

光は「チャネル」の集まりとして扱います。チャネルは次の 5 種類です。

  • 信号（前方のみ、波長 \(\lambda_s\)）
  • 前方励起・後方励起（波長 \(\lambda_p\)）
  • 前方 ASE・後方 ASE（\(\lambda_{\min}\)〜\(\lambda_{\max}\) を \(\Delta\lambda\) 間隔に区切った波長ごと。既定は 970〜1150 nm、2 nm 間隔で 91 波長 × 2 方向）

時間変化、横方向の温度分布、偏光、モード間結合は扱いません。

3上準位の占有率

各位置での定常レート方程式 \(dn_2/dt = 0\) を解きます。チャネル \(k\) による吸収遷移・誘導放出遷移の速度は、光子束 \(\Gamma_k P_k/(h\nu_k A)\) に断面積を掛けたものです。

\[ \frac{dn_2}{dt} = \sum_k \frac{\Gamma_k P_k}{h\nu_k A}\left(\sigma_{a,k}\,n_1 - \sigma_{e,k}\,n_2\right) - \frac{n_2}{\tau} = 0 \tag{1} \]

\(n_1 = 1 - n_2\) を代入して解くと次の式になります。すべてのチャネル（前方・後方の励起、信号、全 ASE）の和を取ります。

\[ n_2(z) = \frac{\displaystyle\sum_k \frac{\Gamma_k\,\sigma_{a,k}}{h\nu_k A}\,P_k(z)} {\displaystyle\sum_k \frac{\Gamma_k\,(\sigma_{a,k}+\sigma_{e,k})}{h\nu_k A}\,P_k(z) + \frac{1}{\tau}} \tag{2} \]

省略している過程: 励起状態吸収、協同アップコンバージョン、イオン対・クラスタによる消光、温度による Stark 準位の占有変化（断面積の温度依存）。Yb では励起状態吸収はほぼ無視できますが、高濃度ファイバーのクラスタやフォトダークニングは実機で効きます（10 章）。

4伝搬方程式と境界条件

チャネル \(k\) の局所的な利得係数 \(g_k\) と、自然放出の湧き出し項 \(s_k\) を次のように置きます。

\[ g_k(z) = \Gamma_k N\left[(\sigma_{a,k}+\sigma_{e,k})\,n_2(z) - \sigma_{a,k}\right] - \alpha \;=\; \Gamma_k N\left(\sigma_{e,k} n_2 - \sigma_{a,k} n_1\right) - \alpha \tag{3} \]
\[ s_k(z) = \begin{cases} m\,h\nu_k\,\Delta\nu_k\,\Gamma_k\,\sigma_{e,k}\,N\,n_2(z), & k \text{ が ASE チャネル}\ (m=2)\\[2pt] 0, & \text{信号・励起} \end{cases} \tag{4} \]

\(m = 2\) は 2 つの偏光モードの分です。伝搬方程式は次のとおりです。

\[ u_k\,\frac{dP_k}{dz} = g_k(z)\,P_k(z) + s_k(z) \tag{5} \]

境界条件は、入射端と出射端に反射がない（完全なアイソレーション）という仮定です。

\[ P_s(0) = P_{s,\mathrm{in}},\quad P_p^{+}(0) = P_{pf},\quad P_p^{-}(L) = P_{pb},\quad P_{\mathrm{ASE},j}^{+}(0) = 0,\quad P_{\mathrm{ASE},j}^{-}(L) = 0 \tag{6} \]

信号は単一周波数として扱い、信号チャネル自体には自然放出項を入れていません。信号波長付近の自然放出は、最も近い ASE チャネルに入ります。

5オーバーラップ係数

信号・ASE・コア励起（基本モード）

ステップインデックスの基本モードをガウス分布で近似し、モードフィールド半径 \(w\) に Marcuse の式を使います。

\[ V = \frac{2\pi a\,\mathrm{NA}}{\lambda},\qquad \frac{w}{a} = 0.65 + \frac{1.619}{V^{3/2}} + \frac{2.879}{V^{6}} \tag{7} \]

強度 \(I(r) \propto \exp(-2r^2/w^2)\) のうち、一様ドープのコア（\(r \le a\)）に入る割合が \(\Gamma\) です。

\[ \Gamma(\lambda) = 1 - \exp\!\left(-\frac{2a^2}{w^2}\right) \tag{8} \]

ASE はチャネルごとにその波長で \(\Gamma\) を計算します。\(V \gt 2.405\)（マルチモード）でも基本モードだけを考えます。

クラッド励起

励起光が内クラッド全体に一様に広がっている（モード混合が十分）と仮定し、面積比を使います。

\[ \Gamma_p = \frac{\pi a^2}{\pi b^2} = \left(\frac{a}{b}\right)^2 \tag{9} \]

このとき式 (2) の励起項は \(\sigma_a P_p/(h\nu_p \pi b^2)\) となり、クラッド断面での平均強度を使っていることになります。

6断面積

内蔵の断面積は、ガラス組成ごとにガウス関数の和で表しています。

\[ \sigma(\lambda) = 10^{-24}\,\text{m}^2 \times \sum_i A_i \exp\!\left[-\left(\frac{\lambda - \lambda_i}{w_i}\right)^{2}\right] \tag{10} \]

これを 850〜1200 nm の範囲で 0.25 nm 間隔の表にし、表の間は線形補間、範囲外は 0 とします。実測データを読み込んだ場合も、同じ表に変換して使います。

7吸収スペックから濃度へ

スペックシートの小信号吸収 \(\alpha_{\mathrm{dB}}\) [dB/m]（基準波長 \(\lambda_{\mathrm{ref}}\)）は、反転がない状態（\(n_2 = 0\)）での式 (3) の値なので、次の関係で \(N\) に換算します。

\[ \alpha_{\mathrm{dB}} = \frac{10}{\ln 10}\,\Gamma(\lambda_{\mathrm{ref}})\,\sigma_a(\lambda_{\mathrm{ref}})\,N \quad\Longrightarrow\quad N = \frac{\alpha_{\mathrm{dB}}\,\ln 10}{10\,\Gamma(\lambda_{\mathrm{ref}})\,\sigma_a(\lambda_{\mathrm{ref}})} \tag{11} \]

クラッド吸収なら \(\Gamma = (a/b)^2\)、コア吸収なら式 (8) の基本モードの \(\Gamma\) を使います。換算は選んだ断面積の表で行うので、組成を切り替えると同じスペック値でも \(N\) が変わります。

8数値解法

空間の離散化

\(z_i = i\,\Delta z\)、\(\Delta z = L/M\)（既定 \(M = 200\)）。1 区間の間で \(g\) と \(s\) を一定とみなせば、式 (5) は厳密に積分できます。

\[ P(z_i + u\Delta z) = P(z_i)\,e^{g\Delta z} + s\,\frac{e^{g\Delta z} - 1}{g} \tag{12} \]

この指数積分を Heun 法（予測子・修正子）で 2 次精度にしています。

\[ \begin{aligned} &\text{予測:}\quad P^{*}_{i+1} = \text{式 (12) に } g_i,\ s_i \text{ を使う}\\ &\text{修正:}\quad n_2^{*} = \text{式 (2) に } P^{*}_{i+1} \text{ を入れる},\quad \bar g = \tfrac12\big(g_i + g(n_2^{*})\big),\ \ \bar s = \tfrac12\big(s_i + s(n_2^{*})\big)\\ &\phantom{\text{修正:}}\quad P_{i+1} = \text{式 (12) に } \bar g,\ \bar s \text{ を使う} \end{aligned} \tag{13} \]

前方・後方の反復

前方チャネルは \(z=0\) から、後方チャネルは \(z=L\) から積分します。各パスでは、反対向きのチャネルの値として直前のパスの結果を使い、前方パスと後方パスを交互に繰り返します（緩和法）。端面出力の変化が次の条件を満たしたら収束とします。

\[ \max_k \frac{\big|P_k^{(m)} - P_k^{(m-1)}\big|}{\big|P_k^{(m)}\big| + 10^{-6}\,P_{\mathrm{ref}}} \lt 10^{-6},\qquad P_{\mathrm{ref}} = P_{pf} + P_{pb} + P_{s,\mathrm{in}} \tag{14} \]

反復の上限は 400 回で、超えると画面に「未収束」と表示します。

数値誤差は実機との差に比べて無視できます。既定の 10/125 プリセットでは、\(M = 100\)・800 や \(\Delta\lambda = 0.5\) nm にしても出力の差は 0.1 % 未満でした。2 次元マップは \(M = 100\)、\(\Delta\lambda = 4\) nm で計算しています。

9表示している派生量

熱負荷

定常状態では、イオンが吸収した正味の光子数と、自然放出で失う光子数が等しくなります（式 (1)）。自然放出光の平均波長を \(\lambda_F = 1005\) nm とすると、残りが熱になります。

\[ q(z) = \sum_k \Gamma_k N\left(\sigma_{a,k} n_1 - \sigma_{e,k} n_2\right) P_k \left(1 - \frac{\nu_F}{\nu_k}\right) + \alpha \sum_k P_k \quad [\text{W/m}] \tag{15} \]

利得スペクトル

収束した \(n_2(z)\) を固定し、弱いプローブ光が全長で受ける正味の利得です。

\[ G(\lambda)\,[\text{dB}] = \frac{10}{\ln 10}\int_0^L \Big\{\Gamma(\lambda) N\big[(\sigma_a+\sigma_e) n_2(z) - \sigma_a\big] - \alpha\Big\}\,dz \tag{16} \]

OSNR

信号波長に最も近い ASE チャネル \(j^{*}\) の出力を、0.1 nm 幅に換算します。

\[ \mathrm{OSNR}_{0.1\,\mathrm{nm}} = 10\log_{10}\frac{P_s(L)}{P^{+}_{\mathrm{ASE},j^{*}}(L)\cdot 0.1\,\text{nm}/\Delta\lambda} \tag{17} \]

飽和パワー・エネルギー

\[ P_{\mathrm{sat}}(\lambda) = \frac{h\nu A}{\Gamma\,(\sigma_a+\sigma_e)\,\tau},\qquad E_{\mathrm{sat}} = P_{\mathrm{sat}}\,\tau = \frac{h\nu A}{\Gamma\,(\sigma_a+\sigma_e)} \tag{18} \]
\[ E_{\mathrm{stored}} = h\nu_s\,N A \int_0^L n_2\,dz,\qquad E_{\mathrm{extract}} \approx E_{\mathrm{sat}}(\lambda_s)\,\ln G_s,\quad G_s = \frac{P_s(L)}{P_s(0)} \tag{19} \]

\(E_{\mathrm{extract}}\) は、現在の CW 動作時の利得をそのままパルスが使えるとした概算です。

非線形しきい値の目安

\[ A_{\mathrm{eff}} = \pi w^2,\qquad L_{\mathrm{eff}} = \frac{1}{P_s(L)}\int_0^L P_s(z)\,dz \tag{20} \]
\[ P_{\mathrm{th}}^{\mathrm{SRS}} = \frac{16\,A_{\mathrm{eff}}}{g_R\,L_{\mathrm{eff}}}\ \ (g_R = 1\times10^{-13}\ \text{m/W}),\qquad P_{\mathrm{th}}^{\mathrm{SBS}} = \frac{21\,A_{\mathrm{eff}}}{g_B\,L_{\mathrm{eff}}}\ \ (g_B = 5\times10^{-11}\ \text{m/W}) \tag{21} \]

どちらも受動ファイバー向けの Smith の判定式に、増幅器用の実効長を当てはめたものです。SBS は信号の線幅がブリルアン利得帯域（数十 MHz）より十分狭い場合の値です。

効率

\[ \eta = \frac{P_s(L) - P_s(0)}{P_{pf} + P_{pb}} \tag{22} \]

分母はファイバーに入った励起パワーです。掃引のスロープ効率は、励起パワー掃引の後半の点に直線を当てはめた傾きです。

熱負荷中量子欠損の部分は正確。背景損失や接続部の局所的な発熱は入っていない

12実機に合わせる手順

  1. 励起波長を実測値にする。使う LD のスペクトルの中心を「励起波長」に入れます。976 nm 帯の LD は動作電流と温度で波長が動くので、実際の動作点で測った値を使います。
  2. 励起パワーはファイバーに入った値にする。コンバイナの出力側で測った値、またはコンバイナの透過率を掛けた値を入れます。
  3. 実効吸収を測って入れる。信号なし・低い励起パワー（吸収が飽和しない範囲）で、長さを変えて励起の透過を測ると実効吸収 [dB/m] が分かります。それを実際の励起波長を基準波長として入力すると、スキュー光の影響もまとめて取り込めます。
  4. 受動損失を背景損失に足す。融着や部品の損失を全長で割って dB/km に換算し、背景損失に加えます（例：0.2 dB を 3 m に分散させると約 67 dB/km）。端に集中する損失を一様に分けるので近似です。
  5. 小信号利得で断面積とオーバーラップを確認する。低出力の動作点で信号波長を変えて利得を測り、利得スペクトル（式 16）と比べます。合わない場合は、メーカーの断面積データを読み込みます。
  6. 高出力の動作点で温度の影響を見る。熱負荷が大きい区間では長波長側の吸収が増えます。短波長（1030 nm 付近）の信号で効率が下がる場合はこれが原因の候補です。
