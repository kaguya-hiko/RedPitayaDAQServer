計算モデル

  • Yb³⁺ を2準位系として扱い、定常レート方程式と伝搬方程式を z 方向に解きます。前方・後方の伝搬を交互に積分し、端面出力の相対変化が 10⁻⁶ 未満になるまで繰り返します（Heun 法・指数積分）。
  • ASE は指定した波長範囲を等間隔のチャネルに分け、前方・後方それぞれに自然放出項 2hνΔν·Γσₑ N₂ を入れています。
  • 信号とコア励起のオーバーラップ Γ は基本モードのガウス近似（Marcuse の式）から、クラッド励起は面積比 (acore/aclad)² から求めています。マルチモードコアでも基本モードとして扱います。
  • 内蔵の断面積は 3 種類のガラス組成（アルミノシリケート、ゲルマノシリケート、リン酸シリケート）の代表的なスペクトル形状をガウス関数の和で再現した近似で、測定値そのものではありません。0.25 nm 間隔の表にして線形補間しています。実測データを読み込むと、それを同じ表に変換して使います。
  • ファイバー品種の一覧は、代表的な形状とスペックの目安です。実際の品番を使うときは、スペックシートのコア径・NA・吸収値で上書きしてください。
  • SRS しきい値は 16·Aeff/(gR·Leff)（gR = 1×10⁻¹³ m/W）、SBS しきい値は 21·Aeff/(gB·Leff)（gB = 5×10⁻¹¹ m/W、狭線幅信号の場合）で見積もっています。Leff は信号パワー分布を出力パワーで割って積分した実効長です。
  • 取り出し可能エネルギーは Esat·ln G（Esat = hν·A/(Γ(σₐ+σₑ))、G は現在の信号利得）で、パルス増幅の目安です。
  • ドープ量はスペックシートの小信号吸収 (dB/m) で指定できます。クラッド吸収は α = 4.34·(acore/aclad)²·σₐ(λ)·N、コア吸収は α = 4.34·Γ(λ)·σₐ(λ)·N として Yb 濃度 N に換算します。976 nm の吸収ピークは鋭いため、基準波長はスペックシートと同じものを選んでください。
  • 熱負荷は平均蛍光波長 1005 nm を基準にした量子欠損と背景損失から見積もっています。
  • 考慮していないもの: 非線形効果の伝搬（SRS・SBS はしきい値の目安のみ）、SPM、フォトダークニング、温度依存性、パルス動作、端面反射による寄生発振。
